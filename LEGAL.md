## Notices included with the application

Settings > About > Open-source licenses provides an offline viewer for the
following files in the installation directory:

- `legal/licenses.html`: license overview and links to the full license texts.
- `legal/licenses/`: Kemu's license and the GPL, LGPL and Apache license texts.
- `NOTICE.txt` and `NOTICE.csv`: host component notices and the component/license
  inventory generated by the emulator build.
- `legal/android/index.html`: notices exported from the same Android product
  output as the system image, including its available partition notices.
- `platform-tools/NOTICE.txt`: notices for platform-tools when that package is
  included in a release.
- `legal/Qt-6.5.3-THIRD-PARTY.txt` and
  `legal/QtWebEngine-6.5.3-Chromium-THIRD-PARTY.txt`: notices for the third-party
  components of the shipped Qt libraries and of the Chromium snapshot in Qt WebEngine.
- `legal/qt-sources.html`: Qt source references and verification status.
- `legal/TRADEMARKS.txt`: trademark ownership and project independence statement.

The original Android notices also remain in the system image. The license viewer
does not change any license or require the user to accept additional terms.

## Qt runtime license and source references

The Windows package retains its existing Qt 6.5.3 AndroidEmu prebuilt and build
workflow. Its Qt-owned runtime code now uses the **GPL-2.0-only** alternative
already offered by Qt. This addresses the Qt-license choice for linking with
GPLv2-only host code; Kemu's own code remains GPL-2.0-or-later. Selecting this
alternative does not require rebuilding Qt or changing upstream grants.
Qt documents it for [Widgets](https://doc.qt.io/qt-6.5/qtwidgets-index.html#licenses)
and [Qt-specific WebEngine code](https://doc.qt.io/qt-6.5/qtwebengine-licensing.html).
Third-party components retain their separate licenses and obligations.

The offline `legal/qt-sources.html` records the provenance found during this
review, including fixed source references, the eight Qt module revisions and the
historical Python build entry point. `legal/Qt-6.5.3-THIRD-PARTY.txt` preserves
the upstream attribution notices of the referenced Qt Base, SVG, Image Formats,
Declarative and Positioning sources for components in the shipped Qt libraries.
Entries used only on other platforms, by modules that are not shipped or by build
tools are omitted; Qt WebChannel and Qt WebSockets have no third-party
attributions. The selected alternatives are GPLv2 for FreeType and its
rasterizer, CC0 for BLAKE2 and MIT for the Vulkan XML specification. These
choices do not replace the other copyright notices or license texts in that file.

`legal/QtWebEngine-6.5.3-Chromium-THIRD-PARTY.txt` contains the Chromium notices
of Qt WebEngine, collected from the Chromium snapshot identified in
`legal/qt-sources.html` using Chromium's upstream license collection rules.
Without the original build directory, it covers every
third-party directory in that snapshot, including components that may not be part
of the Windows libraries.

### Verified prebuilt provenance

- Windows import: official build **11487595**, February 25, 2024.
- The prebuilt module metadata records Qt 6.5.3 and MSVC 19.38.33134.0.

Detailed import records, fixed Qt and Chromium source references, module
revisions and historical build information are recorded in the bundled
`legal/qt-sources.html`. Retrieve all required modules and submodules at the
revisions recorded there.

### Remaining verification

The complete CI manifest for build 11487595 was not available from its public
artifact listing during this review. The exact build-script revision, local
patches and all build inputs therefore remain unverified. The historical source
and build references in `legal/qt-sources.html` narrow the source search, but are
not proof that complete corresponding source has been delivered for these binaries.

The Qt and Chromium notices were collected from the referenced sources, not from
the build output of 11487595. Qt's GPLv2 option resolves the identified choice of
Qt license; it is not certification of every linked or bundled component.
Release maintainers must complete the source verification before claiming the
source obligations are fully satisfied. These updates do not retroactively
change notices or establish provenance for previously published artifacts.

## Component licenses

Upstream emulator and QEMU components retain their original licenses, including
GPLv2-only terms where applicable. Kemu's GPL-2.0-or-later grant applies to its
original code and does not replace upstream licenses.

Kemu's original UI code and `kemu-affinity` use GPL-2.0-or-later and are attributed
separately from upstream components. Third-party components retain their own
copyright notices and license terms. See the bundled host component inventory
and notices for component-specific information.

The Android system, guest kernel and helper programs retain their respective
licenses and redistribution obligations.

## Source code

Use the version shown in About or `VERSION.txt` to select the corresponding
[release manifests](manifests-history). Each version directory contains
`emulator.xml` and `aosp.xml` with the revisions used for that release. Do not
substitute a current branch tip when obtaining source for an older binary.

Additional source locations:

- [Emulator / QEMU and Kemu UI](https://github.com/kuloPo/Kemu-emulator_external_qemu)
- [Linux kernel](https://github.com/kuloPo/Kemu-kernel)
- [Virtual device kernel modules](https://github.com/kuloPo/Kemu-kernel_common-modules_virtual-device)
- [Kernel prebuilts and provenance](https://github.com/kuloPo/Kemu-AOSP_prebuilts_qemu-kernel)

For kernel binaries, use the prebuilt revision selected by the release's AOSP
manifest and its recorded kernel/module source revisions. A binary prebuilt or a
manifest alone is not a substitute for corresponding source. Source delivery must
include the applicable modifications, interface definitions and build/install
scripts required by each license. Keep release source revisions and archives
available alongside the associated binary downloads.

If a matching source revision, archive or build input is missing, report the
release version and component through the
[project issue tracker](https://github.com/kuloPo/Kemu/issues).
